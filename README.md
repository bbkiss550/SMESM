# SME Service Manager

ระบบบริหารงานบริการสำหรับ SME ครอบคลุมลูกค้า ใบงาน ตารางนัดหมาย หัวหน้าช่าง สินค้าและสต๊อก การชำระเงิน การคืนเงิน ใบเสร็จ และรายงาน โดยส่วนติดต่อผู้ใช้งานเป็นภาษาไทย

## เทคโนโลยี

- Java 21 และ Spring Boot 4
- Spring MVC, Thymeleaf, Spring Security และ Spring Data JPA
- PostgreSQL 17 และ Flyway
- Bootstrap 5 พร้อมส่วนประกอบที่ปรับจากธีม `inapp-1.0.0`
- จัดเก็บไฟล์แนบใน Local Storage

## การรันในเครื่อง

ต้องมี Java 21 และ PostgreSQL ก่อนเริ่มใช้งาน จากนั้นสร้างฐานข้อมูลชื่อ `db_service_demo`

คัดลอก `.env.example` เป็น `.env` แล้วกำหนดค่าการเชื่อมต่อจริง โดยเฉพาะ `DB_PASSWORD` ไฟล์ `.env` ถูก ignore และไม่ควร commit ลง Git

```powershell
Copy-Item .env.example .env
.\mvnw.cmd spring-boot:run
```

ระบบใช้พอร์ต `8080` โดยค่าเริ่มต้น หากพอร์ตถูกใช้งานอยู่ให้เปลี่ยน `SERVER_PORT` ใน `.env` เช่น `8081`

เมื่อเริ่มระบบครั้งแรก Flyway จะสร้างโครงสร้างฐานข้อมูลและข้อมูลสาธิตให้อัตโนมัติ

## บัญชีสาธิต

- ผู้ดูแลระบบ: `admin` / `demo1234`
- เจ้าหน้าที่: `staff` / `demo1234`
- หัวหน้าช่าง: `technician` / `demo1234`

ควรเปลี่ยนรหัสผ่านทั้งหมดก่อนใช้งานจริง

## การทดสอบ

```powershell
.\mvnw.cmd test
```

ชุดทดสอบครอบคลุมการเริ่ม Spring Context, การตรวจ schema และการคำนวณ VAT แบบรวมอยู่ในราคาสุทธิ

## ข้อมูลสำคัญในการใช้งาน

- หัวหน้าช่างหนึ่งคนรับงานซ้อนเวลาไม่ได้ งานเดิมมีสิทธิ์ก่อน
- งานที่ปิดแล้วเปิดกลับไม่ได้ ต้องสร้างเป็นงานแก้ที่อ้างอิงงานเดิม
- การยกเลิกงานรองรับไม่คืนเงิน คืนบางส่วน หรือคืนเต็มจำนวน
- VAT 7% คำนวณย้อนจากราคาสุทธิ ไม่บวกเพิ่มกับลูกค้า
- ข้อมูลหลักและรายการเคลื่อนไหวใช้ Audit Fields และ Soft Delete
- ไฟล์แนบถูกเก็บที่ `storage/uploads/jobs` โดยค่าเริ่มต้น

## Docker Compose

กำหนด `POSTGRES_PASSWORD` แล้วรันคำสั่งต่อไปนี้เมื่อ Docker Engine พร้อมใช้งาน

```powershell
$env:POSTGRES_PASSWORD = 'your-password'
docker compose up --build
```
